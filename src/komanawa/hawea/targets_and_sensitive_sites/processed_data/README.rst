A quick overview of the files in this directory follows
=======================================================

- `hawea_r_targets-optimisation_period.p <../processed_data/hawea_r_targets-optimisation_period.p>`_: all river target data
- `head_target_locations.csv <../processed_data/head_target_locations.csv>`_: all head target info
- `indicative_time_mapper.csv <../processed_data/indicative_time_mapper.csv>`_: links for the indicative time mapper
- `lake_g40_0415_curve_data.p <../processed_data/lake_g40_0415_curve_data.p>`_: data for the curves
- `min_fit_lake_g40_0415_curve.p <../processed_data/min_fit_lake_g40_0415_curve.p>`_: fit for the simple model of the lake and well g40_0415
- `min_fit_lake_g40_0415_curve_brute.p <../processed_data/min_fit_lake_g40_0415_curve_brute.p>`_: fit for the simple model of the lake and well g40_0415
- `optimisation_hds_targets-optimisation_period.p <../processed_data/optimisation_hds_targets-optimisation_period.p>`_: all head target data
- `piezo_targets.csv <../processed_data/piezo_targets.csv>`_: list of the processed peizo target data
- `river_target_locs.txt <../processed_data/river_target_locs.txt>`_: text array (model shape) of the river target locations
- `simple_fit_lake_g40_0415.csv <../processed_data/simple_fit_lake_g40_0415.csv>`_: simple fit of the lake data should have been a .p file
- `wetlands.txt <../processed_data/wetlands.txt>`_: text array (model shape) of the wetland locations
