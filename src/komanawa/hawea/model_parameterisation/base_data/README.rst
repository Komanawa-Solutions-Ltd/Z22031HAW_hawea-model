A quick overview of the files in this directory follows
=======================================================


- `README.rst <../base_data/README.rst>`_: this document

- `rch_pilot_points.shp <../base_data/rch_pilot_points.shp>`_: shape file for the recharge pilot points (not used in 3d model)
