Dataset overview
================

- `hawea_r_targets-optimisation_period.p <../../hawea_r_targets-optimisation_period.p>`_: all river target data
- `head_target_locations.csv <../../head_target_locations.csv>`_:all head target info
- `indicative_time_mapper.csv <../../indicative_time_mapper.csv>`_: links for the indicative time mapper
- `lake_g40_0415_curve_data.p <../../lake_g40_0415_curve_data.p>`_: data for the curves
- `min_fit_lake_g40_0415_curve.p <../../min_fit_lake_g40_0415_curve.p>`_:fit for the simple model of the lake and well g40_0415
- `min_fit_lake_g40_0415_curve_brute.p <../../min_fit_lake_g40_0415_curve_brute.p>`_: fit for the simple model of the lake and well g40_0415
- `optimisation_hds_targets-optimisation_period.p <../../optimisation_hds_targets-optimisation_period.p>`_: all head target data
- `piezo_targets.csv <../../piezo_targets.csv>`_: list of the processed peizo target data
- `river_target_locs.txt <../../river_target_locs.txt>`_: text array (model shape) of the river target locations
- `simple_fit_lake_g40_0415.csv <../../simple_fit_lake_g40_0415.csv>`_: simple fit of the lake data should have been a .p file
- `wetlands.txt <../../wetlands.txt>`_: text array (model shape) of the wetland locations
